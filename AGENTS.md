# AGENTS.md

All repository agent guidance lives in [CLAUDE.md](./CLAUDE.md). Read it before
making changes; it applies to every coding agent.

SchoolPilot owns the production API and teacher web app. This repository owns
the ClassPilot browser extension and its separately packaged Windows Chrome/Edge
variants. Legacy `client/`, `server/` and deployment documents are not the
SchoolPilot production application or deployment runbook.

Extension source versions, verified ZIPs, Store publication and managed-device
adoption are separate evidence. Recheck the live version and pending submissions
immediately before any authorized Store upload. Windows development packages do
not establish signed-host or managed-device readiness.
