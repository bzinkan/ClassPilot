# ClassPilot 2.9.3 Class tools correction

Upload `dist/ClassPilot-v2.9.3.zip`, generated by `extension/package-extension.sh` from the clean tagged release commit. Retain the ZIP, SHA-256 and validation evidence. The earlier 2.9.2 archive and tag remain immutable; use this successor for the current release.

Packaged Chrome CI exposed a timer overlay covering the student ClassPilot launcher after reload. The timer now displays at the top right and does not intercept pointer events. A browser regression asserts that a restored paused timer cannot cover the launcher, while retaining actual click, state restoration, and subsequent Class tools interactions. The resilience test also serves its lock destination from an offline HTTPS fixture rather than depending on blocked external DNS.

All Class tools capabilities and the existing 2.9.1 messaging guarantees are retained from the 2.9.2 candidate. No Chrome permissions or managed-policy keys change. The compatible SchoolPilot API/schema must deploy first; new student capabilities and school feature phases remain off until separately enabled through the school rollout controls. See `CLASSPILOT_2_9_2_RELEASE.md` for those contracts.

This release preparation does not upload or publish to Chrome Web Store. Confirm the live version immediately before uploading, use deferred publishing, and complete the established controlled managed-Chromebook checks before publication. The canonical package verifier runs the full Chrome gate against the unpacked archive, including the new timer/launcher regression.
